> **Multi-agent AI system** for bank account opening and KYC verification, combining OCR-based document checks with a guided registration flow.

*March 2026*

**Architecture**

```
User Registration → Streamlit UI
        ├── Document Upload (Aadhar / PAN)
        ├── OCR Verification (Tesseract)
        ├── LLM Verification (Llama3 via Ollama)
        ├── OTP Verification
        └── SQLite Database
```

**Key Features**
- Multiple agents for KYC and account opening workflow
- OCR verification for Aadhar and PAN using **Tesseract**
- **Llama3** (via Ollama) for document/data verification
- **Streamlit** interface for registration, document upload & OTP verification
- **SQLite** database integration

*Oct 2025*

```
Health Parameters → Preprocessing
                        ↓
     Model Training & Evaluation
     (Linear Regression, Ridge,
      Lasso, Random Forest)
                        ↓
     Best Model Selected
                        ↓
     Flask Web App → Deployed on Render
```

- Regression analysis to predict newborn birth weight
- Trained & evaluated **Linear Regression, Ridge, Lasso, and Random Forest** models
- Selected the best performing model
- **Flask**-based web application for real-time prediction
